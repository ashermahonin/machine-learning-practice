# Домашняя работа 2. Списки и словари

Выполнил пять заданий упрощённого варианта. Для строк использовал словари, `split()` и `join()`, для удаления повторов собрал новые списки.

## Как выполнял

1. В [chastota_simvolov.py](chastota_simvolov.py) создал пустой словарь. Для каждого символа увеличиваю счётчик через `get()`. Регистр учитывается, пробелы и знаки тоже попадают в словарь: для `ааба` результат `{'а': 3, 'б': 1}`.
2. В [slova_naoborot.py](slova_naoborot.py) разбил строку на слова, развернул список методом `reverse()` и соединил слова пробелом. Для `Python is really cool` получается `cool really is Python`. Несколько пробелов заменяются одним, знаки остаются рядом со своими словами.
3. В [bez_dublikatov.py](bez_dublikatov.py) перебрал исходный список. Добавляю элемент в результат, только если его там ещё нет. Порядок первых вхождений сохраняется, исходный список не меняется.
4. В [unikalnye_elementy.py](unikalnye_elementy.py) объединил три списка тем же способом. Сначала перебираю списки, затем их элементы. Чтобы обработать больше списков, достаточно добавить их в переменную `lists`.
5. В [tipy_simvolov.py](tipy_simvolov.py) создал словарь с четырьмя счётчиками. Перевожу буквы в нижний регистр и определяю их тип через `if` и `elif`.

В заданиях 3 и 4 исходные данные заданы в начале файлов. В примерах есть вложенные списки и словари: проверка `item not in result` позволяет сравнивать и такие объекты. Равенство определяется обычным сравнением Python.

Для подсчёта букв использовал русский и английский алфавиты. `ё` считается гласной, `й` и английская `y` согласными. `ь` и `ъ` не относятся ни к гласным, ни к согласным и пропускаются. Цифры определяются через `isdecimal()`, пунктуация через категории Unicode, включая кавычки `«»` и многоточие `…`. Пробелы, математические символы, эмодзи и буквы других алфавитов не учитываются.

## Запуск

Нужен Python 3.10 или новее. Дополнительных библиотек нет.

```bash
git clone git@github.com:ashermahonin/machine-learning-practice.git
cd machine-learning-practice
git switch homework-02-kollekcii
python3 chastota_simvolov.py
python3 slova_naoborot.py
python3 bez_dublikatov.py
python3 unikalnye_elementy.py
python3 tipy_simvolov.py
```

В заданиях 1, 2 и 5 строка вводится в консоли. Задания 3 и 4 сразу выводят результат для списков из кода.

Пример подсчёта символов:

```text
Введите строку: Привет, Python! 123
{'гласные': 3, 'согласные': 9, 'цифры': 3, 'пунктуация': 2}
```
