# Домашняя работа 1. Условия, циклы и строки

Выполнил пять заданий упрощённого варианта. Использовал `if`, `elif`, `else`, циклы `for` и `while`, преобразование чисел и методы строк.

## Как выполнял

1. В [summa_chisel.py](summa_chisel.py) организовал ввод через `while True`. Преобразую строку в `float` и прибавляю число к сумме. При первом нечисловом вводе завершаю цикл и печатаю результат.
2. В [zaglavnye_bukvy.py](zaglavnye_bukvy.py) перебрал символы строки. Через `isupper()` проверяю регистр и собираю новую строку из заглавных букв. Порядок букв сохраняется.
3. В [fizzbuzz.py](fizzbuzz.py) перебрал числа от 1 до 100. Сначала проверяю кратность одновременно 3 и 5, затем каждое условие отдельно. Поэтому для 15 получается `FizzBuzz`.
4. В [summa_cifr.py](summa_cifr.py) проверил символы через `isdecimal()`. Каждую найденную цифру перевожу в `int` и складываю: для `a12б3!` результат равен `6`.
5. В [maksimum.py](maksimum.py) прочитал десять чисел. Максимум сначала равен `None`, затем сравниваю с ним каждое число. Это позволяет правильно обработать и набор, состоящий только из отрицательных чисел.

Строки неизменяемы: при добавлении буквы в результат создаётся новая строка, исходная остаётся прежней.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки устанавливать не нужно.

```bash
git clone git@github.com:ashermahonin/machine-learning-practice.git
cd machine-learning-practice
git switch homework-01-usloviya-i-cikly
python3 summa_chisel.py
```

Остальные программы запускаются так же:

```bash
python3 zaglavnye_bukvy.py
python3 fizzbuzz.py
python3 summa_cifr.py
python3 maksimum.py
```

Пример для первого задания:

```text
Введите число (любой текст завершит ввод): 10
Введите число (любой текст завершит ввод): -2
Введите число (любой текст завершит ввод): 2.5
Введите число (любой текст завершит ввод): стоп
Сумма: 10.5
```

Дробные числа вводятся через точку. В первом задании пустая строка, `nan` и `inf` завершают ввод. Если чисел ещё не было, сумма равна нулю. В пятом задании ошибочный ввод не засчитывается: программа запрашивает то же число повторно.

## Проверка

```bash
python3 proverka.py
```

Проверил сумму и остановку ввода, русские и латинские заглавные буквы, все 100 строк FizzBuzz, сумму цифр и максимум. Отдельно проверил пустые строки, отрицательные и дробные числа, повторный ввод после ошибки. Для цифр использую `isdecimal()`: он допускает десятичные цифры Unicode, которые понимает `int()`, и пропускает надстрочную `²`.
