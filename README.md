Три домашние работы по основам Python. Для каждой создана отдельная ветка с решениями, описанием шагов и проверкой. Выполнены все 14 заданий упрощённого варианта.

## Как открыть работу

```bash
git clone git@github.com:ashermahonin/machine-learning-practice.git
cd machine-learning-practice
git switch homework-01-usloviya-i-cikly
```

Для другой работы укажи её ветку. В каждой ветке README содержит ход выполнения, примеры и команды запуска. Проверка запускается командой `python3 proverka.py`.

Нужен Python 3.10 или новее. Все программы работают со стандартной библиотекой. В `main` находится оглавление.
