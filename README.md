# Домашняя работа 3. Функции

Выполнил четыре задания упрощённого варианта и объединил примеры в [funkcii.py](funkcii.py). В работе использовал позиционные аргументы, `*args`, именованные параметры, `return` и обработку ошибок ввода.

## Как выполнял

1. Написал `calculate(*numbers, operation=...)`. Для `sum` начинаю с нуля и складываю аргументы, для `mul` начинаю с единицы и перемножаю их. Неизвестная операция вызывает `ValueError`. Параметр `operation` передаётся по имени.
2. В `read_int()` поместил ввод в бесконечный цикл. Если `int()` не может преобразовать строку, вывожу сообщение и повторяю запрос. После корректного ввода возвращаю число.
3. В `full_path(drive, *parts, ext=..., sep='/')` собрал путь через `join()`. Последний позиционный аргумент после диска содержит имя файла без расширения, предыдущие аргументы содержат названия папок. Добавляю расширение после точки.
4. В `group_by_type(items)` использовал `type()` как ключ словаря. Для каждого типа собираю отдельный список. Порядок объектов сохраняется; `bool` и `int` попадают в разные группы.

В `main()` последовательно вызвал все четыре функции. Условие `if __name__ == '__main__'` позволяет запускать примеры из консоли и импортировать функции без запроса ввода.

## Запуск

Нужен Python 3.10 или новее. Дополнительных библиотек нет.

```bash
git clone git@github.com:ashermahonin/machine-learning-practice.git
cd machine-learning-practice
git switch homework-03-funkcii
python3 funkcii.py
```

Программа покажет сумму и произведение, попросит ввести целое число, затем выведет путь и словарь группировки. Если ввести `abc` или `2.5`, появится сообщение об ошибке и запрос повторится.

Примеры отдельных вызовов:

```python
from funkcii import calculate, full_path, group_by_type

calculate(2, 3, 4, operation="sum")  # 9
calculate(2, 3, 4, operation="mul")  # 24

full_path("c:", "work", "python", "function", "main", ext="py")
# 'c:/work/python/function/main.py'

groups = group_by_type([1, "a", 2, True])
assert groups == {int: [1, 2], str: ["a"], bool: [True]}
```

Без чисел `calculate()` возвращает `0` для сложения и `1` для умножения. Функция `full_path()` формирует строку пути по условию задания, файл на диске не создаёт. Названия папок и имя файла передаются без разделителей по краям. Папки можно не передавать. Расширение допускается с точкой или без неё; пустое расширение оставляет файл без суффикса. Для разделителя Windows можно указать `sep="\\"`.
